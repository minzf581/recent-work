NexaLayer

Live · early access Founder / builder, end to end

NexaLayer is a network session layer for AI agents and browser automation. It sells residential and ISP proxies with per-key and daily spend caps, so an agent can buy and manage SOCKS5 sessions without an open-ended account.

  • Use it through a plain API, or through MCP with npx -y @nexalayer/mcp.
  • When spend hits the cap, the key pauses. Price is re-checked at order time.
  • Early-access launch pricing starts at $0.23/GB, as shown on the public site.
  • I also added NexaLayer Agent, an in-product AI chat I built with RAG and LangChain for intelligent customer support. It lets users manage the proxy network with natural language, and answers customer questions about IP proxies.

I designed and built the product, API, MCP server, documentation, and launch.

ZTProxy

Live · commercial Founder / technical lead

ZTProxy is a commercial residential proxy service for global teams. It offers rotating proxies billed by traffic and static proxies billed per IP / month, with a self-serve dashboard and product sites in English and Chinese.

  • Typical uses include market research, localization testing, and authorized multi-account operations.
  • Around the core service I also built an IP selection and quality-evaluation agent (a custom OpenAI API tool-call loop that scores latency, success rate, geography, anonymity, and price) and an AI support assistant (RAG + LangChain) for proxy users.
  • These proxy products serve thousands of users.

Wanyu AI Fingerprint Browser

Live · commercial Founder / technical lead

Wanyu AI Fingerprint Browser (万域AI指纹浏览器) is a Windows desktop browser for cross-border commerce, advertising operations, and multi-account teams. Each environment can have its own browser fingerprint, proxy, launch settings, and extensions.

  • It also supports environment groups, batch actions, member permissions, operation records, and controlled MCP / agent connections for authorized browser tasks.
  • The product is commercialized and has thousands of paying users. It is listed on the Microsoft Store (last updated 20 October 2026) and has a Windows desktop client.
